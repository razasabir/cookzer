A running list of what's queued up for delivery. Add a task any time — it gets picked up from here, and once it's shipped it's marked Done with the date.

To do

5

  • iOS app — get it onto your iPad via TestFlight

    The iOS shell is built (see Done). Unlike Android, Apple has no free direct-download option — the only way to run it on a real device is TestFlight, which needs a paid Apple Developer Program membership ($99/year). Once that account exists: register the com.cookzer.app App ID, create a distribution certificate + provisioning profile, create an App Store Connect API key, and add all of it as repo secrets (exact steps are commented in .github/workflows/ios.yml). After that, every push uploads a new TestFlight build automatically.

    To do Added Sep 17, 2026

  • Android app — publish to Google Play

    The app itself and a direct-download link are already live (see Done) — this is just the actual Google Play listing now: a Google Play Developer account ($25 one-time), a signing keystore for a real release build, and the first manual store submission. Once approved, the website's download link can point at the Play Store instead of the direct APK.

    To do Added Sep 16, 2026

  • Google + Facebook sign-in: create provider credentials

    The "Continue with Google/Facebook" buttons are live on the sign-in page, but need real OAuth credentials to actually work: a Google Cloud OAuth client and a Facebook Developer app, both with their Client ID/Secret entered into Supabase Dashboard → Authentication → Providers, plus Supabase's callback URL added to each provider's redirect allowlist.

    To do Added Sep 17, 2026

  • Bulk recipe upload

    Add a large batch of recipes to the platform so the library has real depth from day one. Every recipe follows the existing schema, categories, and style already used across the site.

    To do Added Sep 15, 2026

  • Sitewide multi-language support

    Full site available in English, Urdu, Hindi, Arabic, Chinese, Spanish, Italian, French, and Japanese — including right-to-left layout for Urdu and Arabic, a language switcher, and a real translation pipeline for both static UI text and user-generated content.

    To do Added Sep 15, 2026

Won't install? Tap here (especially on Samsung)
  1. Samsung Auto Blocker: Settings → Security and privacy → Auto Blocker — turn it off, or allow this one install when prompted. This is on by default on newer Samsung phones and blocks all sideloaded apps.
  2. Allow installs from your browser: Settings → Apps → (Chrome / Samsung Internet / your browser) → Install unknown apps → Allow.
  3. If Google Play Protect shows a warning, tap "More details" → "Install anyway" — expected for an app that isn't on the Play Store yet.
